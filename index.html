ระบบบริหารจัดการโครงการก่อสร้าง และรายงานหน้างานแบบปิดวงจร (Closed-Loop System)

เลือกบทบาทของคุณเพื่อเข้าสู่ระบบที่ออกแบบเฉพาะทาง:
📱 เหมาะสำหรับมือถือ (Mobile View)
👷‍♂️

LV1: โฟร์แมนหน้างาน

รายงานประจำวัน 2 จังหวะ (เช้า / จบงาน)

ตรวจเช็คคนงานเข้างานรอบเช้า 🌅 ดึงงานย่อยที่ PM อนุมัติล่วงหน้ามาเป็นเป้าหมาย และรายงานผลงานจริงสะสม (%) รอบจบงาน 🌆

✓ โหลดงานที่ PM อนุมัติมาเป็นเป้าหมายอัตโนมัติ
✓ บันทึกยอดคนงาน (+/-) สภาพอากาศ ฝนตก
✓ ถ่ายรูปแถวคนงาน & ผลงานจริงประทับเวลา
✓ ซิงก์ผลงานจริงกลับไปที่แผนสัปดาห์อัตโนมัติ
เข้าสู่หน้ารายงานประจำวัน (โฟร์แมน) ➔
💻 เหมาะสำหรับจอคอม (Desktop-Wide)
📋

LV2: หัวหน้าผู้รับเหมา

วางแผนงานรายสัปดาห์ (Weekly Lookahead)

วางแผนงานสัปดาห์ล่วงหน้า แตกงานย่อย 7 วัน (จันทร์-อาทิตย์) ระบุเป้าหมายปริมาณและคนงาน ส่งให้ PM ตรวจสอบอนุมัติ

✓ สร้างแผนงานสัปดาห์และ Milestone ล่วงหน้า
✓ ตาราง Daily Tasks Builder 7 วัน
✓ ติดตามสถานะการอนุมัติ & ข้อสั่งการจาก PM
✓ ดูความคืบหน้ารวมจากที่โฟร์แมนรายงานจริง
เข้าสู่หน้าระบบวางแผนสัปดาห์ (ผู้รับเหมา) ➔
🖥️ จอคอมพิวเตอร์ (Executive Dashboard)
👔

LV3: ผู้จัดการโครงการ (PM)

อนุมัติแผนงาน + ไทม์ไลน์ Gantt + คลังรายงาน

ตรวจสอบและอนุมัติแผนงานสัปดาห์ของผู้รับเหมาทุกราย ดูกราฟ Gantt ภาพรวมโครงการ และสืบค้นประวัติรายงานประจำวันย้อนหลัง

✓ ศูนย์อนุมัติแผนงาน (Approve / Revision)
✓ แผนภูมิ Gantt ไทม์ไลน์ภาพรวมโครงการ
✓ คลังค้นหารายงานประจำวันย้อนหลังทุกไซต์งาน
✓ เรียกดูภาพถ่ายหน้างานความละเอียดสูง
เข้าสู่ศูนย์บริหารโครงการ (PM) ➔
